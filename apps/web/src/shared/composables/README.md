# shared/composables/

跨工作区共享的 Vue 组合式函数。

| 文件 | 功能 |
|---|---|
| `useAIFetch` | AI API 调用（SSE 流式 + JSON 非流式） |
| `useDynamicAIModels` | 动态获取 AI 模型列表 |
| `useLocalizedAIServices` | AI 服务选项多语言化 |
| `useCommandPalette` | 全局命令面板（快捷操作入口） |
| `useCommandPaletteHotkey` | 命令面板快捷键（Mod+Shift+P） |
| `usePreferencesHotkey` | 偏好设置快捷键（Mod+,） |
| `usePlatformEnv` | 平台环境检测（uTools） |
| `useAccountSyncBootstrap` | 账户+云同步初始化 |
| `useSyncStatusMeta` | 同步状态元数据（图标、文案、颜色） |
