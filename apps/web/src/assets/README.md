# assets/

静态资源文件。

## 目录结构

```
assets/
├── index.css              全局 CSS 入口
├── example/
│   └── markdown.md        默认示例 Markdown 文档
├── images/
│   └── favicon.png        网站图标
└── less/
    ├── global.less        全局样式
    ├── app.less           应用布局样式
    ├── theme.less         主题变量
    └── codemirror-global.less  CodeMirror 编辑器全局样式
```
