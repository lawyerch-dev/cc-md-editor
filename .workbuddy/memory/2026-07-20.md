# 2026-07-20

- 重新设计了 `apps/web/src/shared/components/landing/LandingPage.vue` 首页：
  - 改为 Bento Grid 卡片布局，分三层：输入层、输出层、跃迁层。
  - 新增 5 张「开发中」功能卡片：内容输出中心、影响力名片、信任账户、关系网络、价值变现。
  - 补充了已存在但未展示的「成长教练」与「数据报告」入口。
  - 在首页加入核心哲学文案：从输入到输出、从信任到跃迁。
  - 已上线/开发中状态用徽章区分，开发中卡片不可点击并显示「敬请期待」。
- 同步更新了中英文 i18n：`apps/web/src/i18n/messages/zh-CN/landing.ts`、`apps/web/src/i18n/messages/en-US/landing.ts`。
- 通过 `pnpm run type-check` 验证类型无误。
- 根据用户反馈修复：
  - 根元素改为 `h-screen overflow-hidden`，`<main>` 改为 `flex-1 overflow-y-auto`，解决 `index.html` 中 `body { overflow: hidden }` 导致的无法滚动和底部遮挡。
  - 三层从垂直堆叠改为桌面端横向三列布局（`lg:grid-cols-3`），移动端仍保持单列。
  - 精简了卡片尺寸与 Hero 间距，提升一屏内的信息密度。
- 再次反馈修复：
  - 右上角工具栏 `z-index` 从 `z-10` 提升到 `z-50`，解决 `<main>` 遮挡导致按钮无法点击的问题。
  - 说明：当前为暗色是因系统/用户已设置暗色模式，主题切换恢复可点后可在明暗之间切换。
- 浅色模式暖白风格：
  - 在 `LandingPage.vue` 根元素通过 `:style` 在 `uiStore.isDark === false` 时覆盖 CSS 变量：`--background`、`--card`、`--foreground`、`--muted`、`--border`、`--accent` 等，使用暖色调 HSL（如 `40 20% 97%`）。
  - 仅作用于首页，不影响编辑器等其他页面。
- 更新日志：
  - 在 `changelog-data.ts` 新增 `v2.0.0` 条目，日期为 2026-07-20。
  - 同步更新 `zh-CN/changelog.ts` 与 `en-US/changelog.ts` 的 v2.0.0 标题与 5 条变更说明。
